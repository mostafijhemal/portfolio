**OpenAI** has officially agreed to purchase Pierre Computer Company, an innovative developer known for creating a programmable storage layer built entirely on Git.

This acquisition marks a significant structural upgrade for OpenAI's programming models. The company plans to integrate this Git backend directly into Codex. By doing so, OpenAI is signaling a major strategic push to build and control a comprehensive, end-to-end storage architecture designed specifically to handle code written autonomously by AI agents.
